# Node.js Course

**Full-Stack JavaScript Development with Node.js**
VIVES University of Applied Sciences — Milan Dima

This course takes you from the Node.js basics to building complete back-end applications with Express, MongoDB, authentication, testing and deployment.

---

## Target Groups

This course is shared by three programmes:

| Group | Programme |
|-------|-----------|
| **TI** | Toegepaste Informatica |

## How to Use This Course

Work through the chapters in order — each one builds on the previous:

```mermaid
graph LR
    A[1. Intro] --> B[2. Modules] --> C[3. npm] --> D[4. Express]
    D --> E[5. Middleware] --> F[6. Async JS] --> G[7. MongoDB]
    G --> H[8. Validation] --> I[9. Modeling] --> J[10. Auth]
    J --> K[11. Errors] --> L[12. Testing] --> M[13. Deployment]
```

- Complete the lab exercises at the end of the chapters.
- Run the code examples yourself rather than only reading them.
- Ask course-related questions on the Toledo forum.
